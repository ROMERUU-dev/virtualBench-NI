# Changelog

## 0.1.0

- Primera versión distribuible del proyecto.
- Interfaz gráfica para barridos frecuenciales con NI VirtualBench.
- Modo básico y experto.
- Control de fuente DC integrado.
- Presets de barrido con ayudas contextuales.
- Exportación CSV y SVG.
- Empaquetado para Windows mediante PyInstaller.
